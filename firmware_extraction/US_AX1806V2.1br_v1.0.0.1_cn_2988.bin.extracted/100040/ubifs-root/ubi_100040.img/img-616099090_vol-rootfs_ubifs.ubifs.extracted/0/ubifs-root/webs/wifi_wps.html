使用WPS功能注意事项：

1. 无线网络必须开启。

2. 无线网络加密方式必须是WPA2-PSK、WPA/WPA2-PSK或WPA3-SAE/WPA2-PSK。

WPS功能不支持加密方式为WPA-PSK或WPA3-SAE的无线网络，请先修改无线网络的加密方式再设置。
