CONFIGURATION GUIDE
PROVIDER

选择 AI 提供商后将自动填入默认的 BASE_URL 和 MODEL。也可手动修改以适配自定义端点或新模型。

IDA PRO PATH

指向 ida.exe (Windows) 或 idat64 (Linux) 的绝对路径。确保 IDA 版本 ≥ 7.5 以支持 Python 脚本。

API KEY SECURITY

密钥仅存储在本地，不会上传到任何服务器。所有提供商均使用 OpenAI 兼容的 Chat Completions 接口。

LOG LEVEL

DEBUG 输出最详细，适用于故障排查。生产使用建议保持 INFO 级别。
